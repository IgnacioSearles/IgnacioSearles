# 💻 Ignacio Searles

Software Engineering student at ITBA in Buenos Aires. I like building things close to the hardware, and ML systems that have to run in the real world.

## What I've built
- **pulsa**: my thesis, a real-time Argentine Sign Language to Spanish translator that runs on a phone. MediaPipe landmarks, a CTC Transformer with rotary position embeddings, and TFLite inference in about 12 ms. I also built the real-time API and [JavaScript SDK](https://www.npmjs.com/package/@pulsa/sdk) that serve it, and I'm working on a 3D signing avatar for the other direction. [pulsa.ar](https://pulsa.ar)
- **oqed**: an LLM-guided superoptimizer that rewrites a C/C++ project's hottest functions in faster x86-64 assembly, and proves them equivalent with Z3 when it can. Won [Best Agentic Use Case](https://vimeo.com/1245287584#t=6m3s) at the Meta Global AI Developer Hackathon (one of 14 prizes across 5,367 submissions). [GitHub](https://github.com/IgnacioSearles/oqed)
- **Software for ships**: starting at 16, the only developer of Horamar's fleet software. C++ firmware for an embedded sensor system deployed on two ships, and an offline-first fleet management platform for oil tankers and tugboats that syncs to the cloud when connectivity returns.
- **Robotics**: 7th of 177 countries at the FIRST Global Challenge, including a CubeSat recovered from 30 km.
